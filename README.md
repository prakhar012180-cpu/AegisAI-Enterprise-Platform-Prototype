🛡️ AegisAI Workspace
Production-Oriented AI Engineering & LLM Infrastructure Sandbox

An interactive Streamlit workspace featuring four AI infrastructure modules.

✨ Core Features










🔍 Hybrid RAG Retriever

Dense-style retrieval, BM25-inspired keyword ranking and Reciprocal Rank Fusion.













⚡ Modular Agent Runtime

Pydantic validation, SQL security policies and simulated tool execution.













🔀 Resilient LLM Gateway

Multi-provider routing, rate-limit simulation and automatic failover.













📊 Synthetic Quality Gates

Faithfulness, relevance scoring and automated quality decisions.
